دليل الجودة ودراسة الجدوى

دستور العمل لعام 2026: نضمن تخريج دفعات مؤهلة تقنياً ومهنياً لسوق العمل، وتحقيق أعلى عائد استثمار (ROI) للطلاب مغيري المسار المهني.

دراسة الجدوى الاقتصادية

خارطة الطريق التي تحدد ربحية المشروع وقابلية تنفيذه قبل البدء.

1. الدراسة التسويقية (Market)

📊

الشريحة المستهدفة

  • الخريجون الجدد: للباحثين عن تأهيل لسوق العمل.
  • مغيرو المسار: موظفون يبحثون عن رواتب التكنولوجيا.
  • الطلبة (16+): مهارات متقدمة.

الميزة التنافسية (USP)

التدريب العملي المباشر، توفير فرص التوظيف، الإرشاد المهني 1-to-1.

2. الدراسة الفنية والتشغيلية

⚙️

الموقع والتجهيزات

  • المكان: نموذج "هجين" (Hybrid).
  • Hardware: أجهزة GPU قوية للذكاء الاصطناعي.

الموارد البشرية

محاضرين Senior (Revenue Share) مدير أكاديمي

الأكثر طلباً 🔥
AI

هندسة الذكاء الاصطناعي

بناء تطبيقات ذكية حقيقية وليس مجرد نظريات.

1. الأساسيات: Python (Advanced), Math (Linear Algebra & Stats).
2. المتوسط: Machine Learning, Computer Vision (OpenCV).
3. المتقدم: Generative AI, Prompt Engineering, LangChain Agents.
الهدف: AI Specialist / AI App Developer
مثالي للمحاسبين والإداريين 📊
DS

علم وتحليل البيانات

تحويل البيانات إلى قرارات استراتيجية.

1. الأساسيات: Excel Advanced, SQL, Python Basics.
2. المتوسط: Data Analysis (Pandas, NumPy), Visualization (Power BI).
3. المتقدم: Predictive Modeling, Big Data Basics.
الهدف: Data Analyst / Junior Data Scientist
الأضمن للعمل الحر 💻
FS

تطوير الويب الشامل

بناء مواقع وتطبيقات كاملة من الواجهة للخلفية.

1. Front-End: HTML5, CSS3, JS, React / Next.js.
2. Back-End: Node.js / Python (Django), PostgreSQL.
3. إضافة 2026: AI Integration (دمج نماذج الذكاء الاصطناعي بالمواقع).
الهدف: Full-Stack Freelancer
جديد وسريع ⚡
Au

أتمتة الأعمال والـ AI

حلول تقنية سريعة بدون تعقيدات الكود (Low-Code).

1. الأدوات: No-Code / Low-Code Tools (Make.com, Zapier).
2. التطبيق: ربط تطبيقات SaaS (Google Sheets, Slack, CRM) ببعضها.
3. المتقدم: Building AI Automation Workflows for Business.
الهدف: Automation Consultant
